# Loro — legal pages

The public pages for **Loro**, an offline flashcard app published by
SkyBite sp. z o.o.

Served by GitHub Pages:

| Page | URL |
| --- | --- |
| Landing | `https://<user>.github.io/loro-legal/` |
| Privacy policy | `https://<user>.github.io/loro-legal/privacy.html` |

The privacy policy URL is what goes into the Play Console under
**App content → Privacy policy**.

## Keeping it in sync

`privacy.html` is a copy of `store/privacy-policy.html` in the app repository,
which is where it is edited. Copy it across when it changes, and update the
"Last updated" date in both.

Nothing here is generated; both files are plain HTML with no build step.
